# CEFA - Sistema Independiente de Certificación Escolar

Sistema de administración escolar, cálculo de promedios, registro de alumnos y vista de certificados lista para imprimir o exportar a PDF.

## Características

- Panel administrativo para capturar información académica.
- Registro persistente usando `localStorage`.
- Cálculo automatizado de promedio institucional.
- Gestión de materias con calificaciones.
- Vista previa de certificado con diseño institucional premium.
- Impresión y exportación a PDF compatible con CSS `@media print`.
- Carga de datos demo para pruebas rápidas.
